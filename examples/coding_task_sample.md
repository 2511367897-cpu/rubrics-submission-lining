# 编程题质检样例：判断质数

## 题目 Prompt

给定一个整数 `n`，判断它是否为质数。  
如果是质数，输出 `true`；否则输出 `false`。

### 输入约束

- `n` 为整数。
- `-10^9 <= n <= 10^9`。

### 输出要求

- 只输出 `true` 或 `false`。

## Gold Answer / 参考答案要点

1. 质数定义：大于 1，且只能被 1 和自身整除。
2. `n <= 1` 时应返回 `false`。
3. `n == 2` 时应返回 `true`。
4. 偶数且大于 2 时应返回 `false`。
5. 只需要检查到 `sqrt(n)` 即可，不需要遍历到 `n - 1`。
6. 时间复杂度可以优化到 `O(sqrt(n))`。

## 参考实现 Python

```python
def is_prime(n: int) -> bool:
    if n <= 1:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False

    i = 3
    while i * i <= n:
        if n % i == 0:
            return False
        i += 2
    return True
```

## 评分 Rubric

| 维度 | 分值 | 评分点 |
| --- | ---: | --- |
| 正确性 | 5 | 正确定义质数；能判断合数；核心逻辑无误 |
| 完整性 | 2 | 覆盖 `n <= 1`、`n == 2`、偶数、平方根边界 |
| 可解释性 | 2 | 说明为什么检查到 `sqrt(n)`；能解释复杂度 |
| 格式规范 | 1 | 输出 `true/false`，结构清楚 |

## Pass 示例

- 能正确处理 `-1, 0, 1, 2, 3, 4, 9, 17`。
- 说明 `sqrt(n)` 优化原因。
- 输出格式符合题目要求。

## Fail 示例

- 把 `1` 判断为质数。
- 只判断奇偶，不检查其他因子。
- 忽略负数和 0。
- 输出大段解释但没有最终 `true/false`。
